Política de privacidad de la aplicación «Elemental»

Última actualización: noviembre de 2026.

Qué es esta aplicación

«Elemental» es una herramienta de uso personal del autor del canal de YouTube Elemental. Sirve únicamente para subir y programar los vídeos de ese canal mediante la API de datos de YouTube (YouTube API Services). No está abierta al público ni tiene otros usuarios.

Qué datos usa

  • La autorización que el propio autor concede a su canal de YouTube, para subir vídeos, miniaturas y subtítulos y programar su publicación.
  • No recoge, guarda, vende ni comparte datos de ninguna otra persona.
  • No usa cookies ni herramientas de seguimiento.

Cómo se guarda la autorización

La autorización se guarda de forma cifrada como secreto en la cuenta privada del autor y solo se usa para las subidas a su propio canal. Puede revocarse en cualquier momento en myaccount.google.com/permissions.

Servicios de terceros

Esta aplicación usa YouTube API Services. Al usarla se aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Contacto

Para cualquier consulta sobre esta política, escribe a través del canal de YouTube Elemental.
